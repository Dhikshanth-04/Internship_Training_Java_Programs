1. Exception Handling : 

    * Exception handling is the process of handling the Exception, which causes the abrupt termination of the program.
    * If the programmer misses to handle the Exceptions, Java itself has its default Exception handler, the exception object is handled by that handler.
    * The abrupt termination of the program is caused by 2 reasons, Error and Exception.
    * Errors are raised due to the faulty coding and Exceptions are raised due to the faulty inputs. 
    * There are two different types of exceptions, Checked and Unchecked exception.
    * Checked exceptions are the exceptions, must be handled by the programmer.
    * Unchecked exceptions are the exceptions, may or may not be handled, but the program would execute.
    * There are different methods of handling an exception, Try-catch-finally blocks and ducking an exception.
    * The risky part of the code is written inside the try block and the excpected exceptions are written in the catch block, finally block is executed at any cost.
    * Ducking an exception is the process of writting the method with the keyword throws, mentioning that the method may cause an exception.
    * That exception object will be handled by the caller of the method. 

    Code;
    class main{
        public static void main(String[] args){
            Scanner sc = new Scanner(System.in);
            try{
                int numerator = sc.nextInt();
                int denominator = sc.nextInt();
                System.out.println("The division : " + numerator/denominator);
            }
            catch(ArithmaticException  e){
                System.out.println(e);
            }
            catch(InputMismatchException e){
                System.out.println(e);
            }
            catch(Exception e){ //Genric Exception
                System.out.println(e);
            }
            finally{
                System.out.println("Program execution completed");
            }
        }
    }

2. Constructors : 
    * Constructors are the special methods in java, which does not have any return type and written exactly with the name of the class. 
    * Constructors are the default setters, which are used to set the value of the data members in the class. 
    * These Constructors are called, during the creation of the object for a class.
    * There are three different type of constructors - Zero parameterised, Parameterised, Default constructors.
    * If the programmer misses to the write the constructor, Java itself has its initiates the default constructor.
    * Constructor can be overloaded, and can be called within the constructor is called constructor chaining.
    
    Code;
    class Employee{
        public  Employee(){
            System.out.println("Constructor called");
        } 
    }
    class Main{
        public static void main(String[] args){
            Employee e = new Employee(); //Constructor called
        }
    }

3. Why strings are immutable in java ?
    * Strings are the collections of characters enclosed within the double qutoes, there are two different types of Strings - immutable and mutable.
    * immutable strings are the strings, which cant be modified further. Because 90% of the data in the real world were strings, so povide an additional security and making them thread safe.
    * Strings are stroed in the string constant pool, If the strings are created with the new, it would be stored outside the string constant pool. 
    * Duplicate strings are not allowed inside the string constant pool, but its allowed outside the string constant pool.
    Code;
    main(){
        String str1 = "Java"; //str1 - 1000
        String str2 = "Java"; //str2 - 1000
        //Both the strings are created inside the string constant pool, but the memory address for the both the varibales would be same.

4. Multi-Threading : 
    * At the beginning, threads are the light weight and smallest executionary object of the whole process. 
    * The multiple threads executing concurrently on the processor, the switching speed is so high that, it seems to be simultaneous.
    * In this case, there arises the issue of deadlock, where both the threads are waiting for the same resources to be unlocked, but remains infinitely waiting.
    * Multi threading can be acheived by two types - Extending the thread and Implementing the runnable interface. 
    * Runnable is the functional interface, where it contains only on method caled run(), it has to be implemented in the class. 
    * The method should not be called as run(), Because it results in the sequential execution, the method has to be called as start(), it creates the new thread in java and execute independently. 

    Code;
    class A implents runnable{
        public void run(){
            for(int i=0; i<10; i++){
                System.out.println(i);
            }
        }
    }
    class B implents runnable{
        public void run(){
            for(int i=10; i<20; i++){
                System.out.println(i);
            }
        }
    }
    class Main{
        public static void main(String[] args){
            A a = new A();
            B b = new B();
            a.start();
            b.start();
        }
    }

5. Abstraction :
    * Abstraction is the process of hiding the implementation and providing the essential details to the users. 
    * The keyword abstract is used to create abstract method and abstract class. The abstract methods are the methods, which does not have body.
    * Class extending the abstract should provide the body for the abstract method.
    * We cant create the object for the abstract class, because it has an abstract method.
    * Abstract class can also have a concrete methods. Besides, the abstract class can have constructors.
    Code;
    abstract class A{
        abstract void demo();
    }
    class B extends A{
        @Override 
        public void demo(){
            System.out.println("Body provided in child class");
        }
    }
    class Main{
        public static void main(String[] args){
            B b = new B();
            b.demo();
        }
    }

6. Polymorphism :
    * Polymorphism is the greek word, in which poly means many and morphism means forms. In java Polymorphism means, one methods which does different operations on different situations. 
    * There are two different type of Polymorphism, run time Polymorphism and compile time Polymorphism.
    * Run time Polymorphism is acheived by method overriding and the compile time Polymorphism is acheived by method overloading. 
    * Compile time Polymorphism is also known as false Polymorphism, where multiple methods are written with same name and different parameters and different return types, which method to be executed is defined by the set of arguments passed to the method.
    * Run time Polymorphism is also known as True Polymorphism, where the parent class methods will be overriden by the child class methods and executed according to the object creations.
    
    Code - Compile time Polymorphism;
    int add(int a, int b) return a+b;
    double add(double a, double b) return a+b;
    main(){
        add(2.2, 5.5);
        add(3, 5);
    } 

    Code - Runtime Polymorphism;
    class parent{
        void run(){
            System.out.println("Parent");
        }
    }
    class Child extends parent{
        @Override
        void run(){
            System.out.println("Child");
        }
    }
    class Main{
        public static void main(String[] args){
            Parent ch = new Child();
            ch.run(); //Child
        }
    }
