Execution of JavaScript has two phases, Memory allocation phase and execution phase. In memory phase, varibales and functions are stored in the memory first, before the code actually executes line by line.

Hoisting is the JavaScript's behaviour, in which the variables are moved to the top of their scope during memory creatin phase. var is hoisted and initialised with undefined, besides let and const are hoisted and remains in the temporal dead zone, untill its declaration executed.

Temporal Dead Zone is the time between the memory allocation and actual declaration execution. The DOM API is the methods and properties. API methods are the actions performing on html elements and API values are accessing the html elements

DOMContentLoaded is activated when the whole HTML file is loaded, except the external resources. Window Load is activated when the whole html file is ready along with the external resources.
